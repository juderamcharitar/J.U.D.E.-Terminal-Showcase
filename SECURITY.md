# Security reporting

Do not publish credentials, private records, or exploit details in a public issue.

If this repository's Security tab offers **Report a vulnerability**, use that private channel. If it is unavailable, open a minimal issue asking the maintainer for a private reporting channel, without sensitive details or attachments.

The free hosted terminal is a shared demonstration environment with temporary server storage. Use public or non-confidential sample inputs. This showcase contains no production credentials, deployment configuration, private datasets, database backups, or trained models.
