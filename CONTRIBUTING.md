# Feedback and contributions

This repository hosts the public showcase; the production implementation is maintained separately.

For a reproducible issue, include the module/page, public asset or minimal non-confidential example, timeframe, relevant settings, browser, expected behavior, and observed behavior. Explain whether a result was blocked or unsupported rather than omitting the displayed evidence message.

Do not attach credentials, private datasets, account databases, or personal financial records. See [security reporting](SECURITY.md) for suspected security problems.

Documentation corrections and improvements to the standalone example are welcome as proposals. Submitting an issue or pull request does not grant a new software license; see [NOTICE](NOTICE.md).
